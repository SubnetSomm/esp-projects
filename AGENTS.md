# Repository workflow

- For each completed project update, run appropriate checks, commit with a descriptive message, and push to origin. The user has authorized ongoing GitHub updates. Report any synchronization failure.
- Preserve previous local firmware and documents in ../FirmwareArchives before replacing them. Do not delete the user's historical copies.
- Never publish device credentials, private archives, generated build products, or sensor exports. Inspect staged changes before committing.
- Do not force-push or rewrite published history. Preserve unrelated projects and remote changes.
